如何部署到公网
方法一：Vercel（推荐，免费）
1. 注册 vercel.com 账号
2. 安装 CLI：npm i -g vercel
3. 在文件目录运行：vercel deploy
4. 获得公网链接后，用该链接打开本页面
5. 点击二维码按钮即可扫码访问
方法二：GitHub Pages
1. 在 GitHub 创建新仓库
2. 上传 zhbch-app.html 文件
3. 开启 Settings > Pages
4. 通过公网链接打开后扫码
方法三：手机直接打开
1. 将 zhbch-app.html 发送到微信/邮箱
2. 在手机上用浏览器打开文件
3. 无需扫码，直接体验
方法四：电脑开热点分享
1. 电脑和手机连同一 WiFi
2. 用 python -m http.server 8080 启动
3. 查看电脑局域网 IP（如 192.168.1.x）
4. 将代码中链接改为 http://你的IP:8080/zhbch-app.html
5. 手机微信扫码即可打开
